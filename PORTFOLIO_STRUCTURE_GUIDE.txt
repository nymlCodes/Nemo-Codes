3. DATA LAYER & BACKEND API INTEGRATION
================================================================================
The portfolio uses the backend database/server as its exclusive source of truth:
- Environment Variable: `NEXT_PUBLIC_SERVER_URL` in `.env` (e.g. `http://localhost:5000/`)
- Fetching All Projects (`src/lib/projects.ts`):
  * Reads `process.env.NEXT_PUBLIC_SERVER_URL`
  * Queries `${baseUrl}/projects` with `{ cache: 'no-store' }`
  * The live API response is directly returned and rendered.
  * `fallbackProjects.ts` has been completely deleted from the codebase.
  * If the backend server fails or is unreachable, the UI renders a genuine server error state rather than masking failure with hardcoded data.
- Fetching Single Project Details (`src/lib/getProjectById.ts`):
  * Queries `${baseUrl}/projects/:id` directly for 24-character hex ObjectIds.
  * If a human-readable slug is supplied (e.g., 'petnest'), it looks up the item dynamically from the live `${baseUrl}/projects` API list.
  * Returns the full project object dynamically from MongoDB to the details view.

4. TWO-TIER PROJECT ARCHITECTURE (SHOWCASE VS. DETAILS)
================================================================================
The portfolio separates projects into two distinct, focused user experiences:

A. PROJECTS SHOWCASE GALLERY (`/projects` -> `ProjectsClient.tsx`)
- Purpose: A curated visual gallery highlighting key works.
- Information shown:
  * Crisp, sharp project preview image (original colors & contrast, zero grayscale filter)
  * Project title
  * Concise description excerpt
  * Minimal technology badges (top 3-4 technologies)
  * Prominent "View Details" call to action linking to `/details/[id]` or `/projects/[id]`
- Preserves the 4 bespoke editorial showcase scenes:
  * Scene 01: Asymmetric Monumental Stage (with architectural corner crosshairs)
  * Scene 02: Panoramic Full-Bleed Viewport Canvas with floating HUD strip
  * Scene 03: Split-Schematic Canvas with side-by-side technical narrative
  * Scene 04: Monolith Magazine Canvas with typographic background motif
  * Scene 05+: Alternate creative scenes for any remaining projects
- Dynamically maps projects from the backend without hardcoded title lookups.

B. PROJECT DETAILS PAGE (`/details/[id]` and `/projects/[id]`)
- Purpose: Complete, in-depth architectural breakdown of an individual project.
- Information rendered dynamically from backend data:
  * Full project title, category, and status badge
  * Complete in-depth description
  * Full-resolution, crisp hero preview image
  * Timeline duration and team structure metadata
  * Complete framework and technology stack badges
  * Engineering highlights & features checklist
  * Technical challenges & architectural resolutions (Problem Diagnosis & Solution)
  * Retrospective lessons learned
  * Planned roadmap & future enhancements
  * External launch links (Live Application, Client Repository, Server Repository)

5. GLOBAL NEMO TYPOGRAPHIC WATERMARK
================================================================================
- Implementation: `src/components/NemoBackground.tsx`
- Rendered globally via `HomeClient.tsx` so it appears on ALL routes:
  Home (`/`), About (`/about`), Skills (`/skills`), Education (`/education`),
  Projects (`/projects`), Project Details (`/details/:id`, `/projects/:id`),
  and Contact (`/contact`).
- Visual Characteristics:
  * Large, bold typography: "NEMO" in Syne/Outfit ultra-bold (font-weight: 900)
  * Size: `clamp(6rem, 22vw, 27rem)` with responsive scaling
  * Opacity: calibrated to ~0.14 - 0.18, clearly visible and recognizable while remaining behind foreground content
  * Pure white / off-white with subtle glow text-shadow
  * Subtle animation: ultra-slow 22-second floating breathing cycle (vertical translation + gentle scale), subtle opacity pulse, and mouse parallax
  * Strict overflow containment (`overflow-hidden`, `max-w-full`) preventing horizontal scrollbars across all screen widths.

6. BACKGROUND ATMOSPHERE — SUBTLE WIND ENGINE
================================================================================
- Implementation: `src/components/AnimatedBackground.tsx`
- Replaced old upward particles with an organic, subtle wind breeze effect:
  * HTML5 Canvas running at 60fps with low CPU/GPU footprint
  * Draws 30-36 delicate flowing wind streaks moving from left to right with gentle sine-wave waves
  * Soft opacity (0.03 to 0.08) with linear gradient fades at line ends
  * Tiny drifting air motes floating smoothly along the wind vector
  * Provides air, motion, and depth without competing with content or typography
  * Visual hierarchy:
    1. Content (`z-10`)
    2. NEMO Watermark (`z-0`)
    3. Subtle Wind Atmosphere (`-z-20`)
    4. Base Dark Charcoal Vignette (`-z-30`)
  * Respects `prefers-reduced-motion` and automatically pauses when the tab is hidden.
